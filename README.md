# 📦 Open Source Projects

## 🛡️ ServiceGuard Stack

Zero-trust authentication for Node.js microservices using **HMAC-signed JWT request envelopes**.

Features:

- 🔐 Request authenticity and integrity verification
- ⏱️ Short-lived signed tokens
- 🔄 Replay attack protection with pluggable nonce stores
- 🧩 Express, NestJS and Fastify integrations
- ⚡ Zero runtime dependencies
- 📘 Full documentation and security model

🔗 GitHub: https://github.com/Manik3112/serviceguard-stack  
📦 npm: https://www.npmjs.com/package/serviceguard-stack
